## Agent skills

### Issue tracker

Issues are tracked in this repository’s GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the five default canonical labels. See `docs/agents/triage-labels.md`.

### Domain docs

Domain documentation uses the single-context layout. See `docs/agents/domain.md`.

### Language policy

Write recruiter-facing repository content in Spanish: the README, public guides
linked from it, GitHub Issue and pull-request titles and bodies, commit
descriptions, and branch descriptions. Use conventional commit types and
technical identifiers unchanged; write branch slugs in Spanish without accents.
The product interface remains bilingual. Internal agent and architecture
documents may remain in English unless they are linked from the README.
